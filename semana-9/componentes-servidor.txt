Sistema operativo: Es el software principal del computador o servidor. Administra los recursos del sistema y permite 
ejecutar aplicaciones como Node.js.

Node.js:
Es un entorno de ejecución para JavaScript. Permite ejecutar aplicaciones y servidores fuera del navegador web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación utilizado por las aplicaciones. El servidor escucha en el puerto 3000 para recibir solicitudes.

Logs: Son registros de eventos y actividades del sistema. Ayudan a monitorear el funcionamiento del servidor y detectar 
errores.
